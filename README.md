
## ORBITRIX — Agency Landing Page

A modern, high-performance agency landing page built with Next.js, Tailwind CSS, and Framer Motion. Designed to showcase services, portfolio projects, and convert visitors into clients with a premium UI experience.

## Overview

ORBITRIX is a precision-driven digital agency landing page focused on:

- Scalable web development
- Automation systems
- ERP solutions
- Agentic AI products
